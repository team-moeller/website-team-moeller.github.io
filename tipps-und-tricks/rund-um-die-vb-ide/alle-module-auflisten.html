Alle Module auflisten

Funktion

Diese Prozedur listet alle vorhandenen Module auf.

Code

Public Sub AlleModuleAuflisten() 

 
'Variablen deklarieren 
Dim vbc As VBIDE.VBComponent 

 
For Each vbc In Application.VBE.ActiveVBProject.VBComponents 
Debug.Print vbc.Name 
Next 

 
End Sub

Beschreibung

Es wird die Auflistung "VBComponents" durchlaufen. Der Name jedes Objektes wird im Direktfenster ausgedruckt.

Verweise

Damit dieser Code funktioniert, ist folgender Verweis erforderlich:

  • Microsoft Visual Basic for Applications Extensibility 5.3
