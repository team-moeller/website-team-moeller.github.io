TM - MausradScrolltInMemofeld
Version 1.15

In einem Memofeld können schnell mehrere Zeilen zusammenkommen. Um alle Zeilen auf dem vorhandenen Platz darstellen zu können kann eine vertikal Bildlaufleiste aktiviert werden. Leider funktioniert das Mausrad in diesem Fall nicht (wie erwartet). Auch wenn sich der Cursor in einem Memofeld befindet wechselt das Mausrad in Versionen bis einschließlich Access 2003 den Datensatz. Ab Access 2007 hat das Mausrad im Memofeld und im Datensatz keine Wirkung. Dieses Manko behebt die folgende Beispieldatenbank.

Folgende Features stehen zur Verfügung:

  • In einem Memofeld scrollt das Mausrad die vertikale Bildlaufleiste.
  • Außerhalb des Memofeldes wechselt das Mausrad weiterhin den Datensatz. Dies gilt für alle Access-Versionen.
  • Über Bedingte Kompilierung kann dieses Feature ein- und ausgschaltet werden.

 

Diese Anwendung wurde mit grosser Sorgfalt erstellt.
Eine Haftung jeglicher Art wird jedoch ausdrücklich ausgeschlossen.
