TM - DownloadFileFromURL
Version 1.0

Diese Beispieldatenbank stellt ein Klassenmodul zur Verfügung. Mit Hilfe dieses Klassenmoduls ist es möglich, eine Datei aus dem Internet herunterzuladen. Dabei wird der Fortschritt angezeigt und der Download kann abgebrochen werden. Über verschiedene Events wird der aufrufende Code über den Downloadfortschritt und über Statusänderungen informiert. Fehler während des Ablaufs werden ebenfalls per Ereignis mitgeteilt.

Das beigefügte Testformular zeigt die grundsätzliche Vorgehensweise. Der dafür notwendige Code ist auf Grund seiner Kürze sehr übersichtlich.

Folgende Features stehen zur Verfügung:

  • Download einer Datei aus dem Internet.
  • Visualisierung des Downloadfortschritts über Fortschrittsanzeige möglich.
  • Statusänderungen weden mitgeteilt.
  • Download kann abgebrochen werden.
  • Fehler werden als Ereignis veröffentlicht.
