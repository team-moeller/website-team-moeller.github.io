TM VBA-Obfuscuator
Version 1.3.1


Beim Codieren geben Sie sich alle nur erdenkliche Mühe, um Ihren Code leicht verständlich und damit wartbar zu machen. Dazu teilen Sie Ihren Code mittels Leerzeilen in logische Blöcke ein. Die Struktur Ihres Codes heben Sie durch entsprechende Einrückungen hervor. Am Ende fügen Sie noch Kommentare ein. Auch eine geschickte Benennung von Variablen und Konstanten hilft Ihnen dabei, Ihren Code leichter verständlich zu machen. Wenn Sie dann noch Funktionen und Prozeduren mit sprechenden Namen versehen, tun Sie einen weiteren Schritt, um das Verständnis Ihres Codes zu erleichtern.

Diese leichte Verständnis haben aber nicht nur Sie. Jeder, der Ihren Code liest, profitiert von Ihren oben genannten Maßnahmen. Wenn Sie jetzt Ihren Code weitergeben, geben Sie ihr gesamtes KnowHow weiter. Dies ist nicht unbedingt immer gewollt. In solchen Fällen erstellen Sie entweder eine MDE-Datei - oder Sie verschleiern Ihren VBA-Code. Dazu müssen Sie alle oben genannten Maßnahmen rückgängig machen. Auf diesem Weg erschweren Sie einem Dritten das Verständnis Ihres Codes. Dabei hilft Ihnen der TM VBA-Obfuscuator.

Der TM VBA-Obfuscuator bietet Ihnen zur Zeit folgende Möglichkeiten:

  • Leerzeilen können entfernt werden.
  • Einrückungen können entfernt werden.
  • Kommentare können entfernt werden.

 

Der TM VBA-Obfuscuator ist als Add-In für den VBA-Editor ausgestaltet und kann ab Access 2000 eingesetzt werden.

Diese Anwendung wurde mit grosser Sorgfalt erstellt.
